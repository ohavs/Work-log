# ⏱️ מעקב שעות עבודה

אפליקציית **PWA** פשוטה, נקייה ומעוצבת למעקב אחר שעות עבודה — בעברית מלאה ומיושרת מימין לשמאל.
עוקבת אחרי חודשים, ימים, שעות ושכר, עם שמירה בענן (Firebase) וייצוא ל‑PDF ו‑CSV.

## 🔗 קישור חי

**[https://ohavs.github.io/Work-log/](https://ohavs.github.io/Work-log/)** — פתחו בטלפון והתקינו למסך הבית ("הוספה למסך הבית").

## ✨ יכולות

- **מעקב שעות מסודר** — לפי חודשים, ימים ורישומים, עם חישוב אוטומטי של שעות נטו (כולל הפסקות ומשמרות לילה שחוצות חצות).
- **שעון נוכחות חי** — כפתור "התחלת עבודה" שמודד את הזמן בזמן אמת ויוצר רישום אוטומטי בסיום.
- **לוח בקרה חודשי** — סך שעות, ימי עבודה ושכר משוער במבט אחד.
- **ימי חופשה ומחלה** 🏖️🤒 — סימון ימים ללא עבודה וספירה נפרדת שלהם.
- **סיכום שבועי** — פירוק השעות לפי שבועות עם גרף התקדמות.
- **שכר לפי שעה** — חישוב שכר אוטומטי, עם אפשרות לשכר שונה לרישום בודד.
- **יעד חודשי** — פס התקדמות ליעד שעות שהגדרתם.
- **ייצוא ל‑PDF ו‑CSV** — דוח חודשי מעוצב (PDF) או קובץ לאקסל (CSV), ישירות מהדפדפן.
- **שמירה בענן** — סנכרון בין מכשירים דרך Firebase והתחברות עם Google (אופציונלי).
- **עובד גם לא מקוון (Offline)** — התקנה כאפליקציה במסך הבית, שמירה מקומית במכשיר.
- **מצב כהה** 🌙 ומצב בהיר ☀️.

## 🚀 הפעלה מהירה (מקומית)

האפליקציה היא סטטית לחלוטין — אין צורך בהתקנות. הריצו שרת מקומי כלשהו:

```bash
python3 -m http.server 8000
# ואז פתחו: http://localhost:8000
```

מיד מהרגע הראשון האפליקציה עובדת ושומרת נתונים **מקומית במכשיר**. אין חובה ב‑Firebase.

## ☁️ הפעלת שמירה בענן (Firebase) — אופציונלי

1. צרו פרויקט ב‑[Firebase Console](https://console.firebase.google.com).
2. הוסיפו **Web App** והעתיקו את אובייקט ההגדרות (`firebaseConfig`).
3. הדביקו אותו בקובץ [`js/config.js`](js/config.js).
4. ב‑Firebase הפעילו:
   - **Firestore Database**
   - **Authentication** → ספק **Google**
5. פרסמו את חוקי האבטחה מהקובץ [`firestore.rules`](firestore.rules).

לאחר מכן ייפתח בהגדרות כפתור **"התחברות לחשבון Google"** לסנכרון בין מכשירים.

## 🌐 פריסה (Deploy)

עם [Firebase Hosting](https://firebase.google.com/docs/hosting):

```bash
npm install -g firebase-tools
firebase login
firebase deploy
```

או כל אחסון סטטי אחר (Netlify, Vercel, GitHub Pages) — פשוט העלו את התיקייה כמות שהיא.

| `sw.js` | Service Worker (עבודה לא מקוונת) |
| `manifest.webmanifest` | הגדרות PWA להתקנה |
